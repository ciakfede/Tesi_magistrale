# Tesi_magistrale

All'interno di questa repository sono contenuti gli script Python necessari ad implementare una versione modificata della rete neurale NavNet, utile per stimare la posizione di un drone sottomarino autonomo in presenza di solo DVL e sensori IMU.
Nella cartella Testo_tesi, invece, sono contenuti tutti i file utili a generare il file pdf associato alla tesi di laurea tramite VSCode con estensione Latex Workshop. 

Per poter eseguire gli script occorre introdurre una cartella Telemetrie/, contenente i file csv di telemetria di ogni missione.
